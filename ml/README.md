\# VAYUNEX – Machine Learning



\## Overview

VAYUNEX is an AI-driven hyper-local weather prediction system for severe weather early warnings.



\## Prediction Targets

\- Thunderstorm

\- Cloudburst

\- Flash Flood



\## Prediction Horizons

\- 2 Hours

\- 4 Hours

\- 6 Hours



\## Current Progress
