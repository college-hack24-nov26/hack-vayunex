# VAYUNEX – Machine Learning Development

## Overview
VAYUNEX is an AI-driven hyper-local weather prediction system designed to support early warnings for severe weather conditions.

## Current Development Status
**Phase:** Initial ML Development

- Initial weather data collection activities started.
- ERA5 weather data collection and exploration initiated.
- Python-based Machine Learning environment setup started.
- Initial data organization and preparation planning underway.
